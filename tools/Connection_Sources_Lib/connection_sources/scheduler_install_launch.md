Order matters — unregister the scheduler before deleting scheduler/, or you'll leave an orphaned Windows task pointing at a deleted launcher:

cd C:\Users\foueslati\Usine_Agentique_Testing
$P="C:\Users\foueslati\Usine_Agentique_Testing\Talan_Factory\Talan_usine_config"
$S="C:\Users\foueslati\Usine_Agentique_Testing\Talan_Factory\_bmad_state"

# 1. unregister first
& "Talan_Library/Connection_Sources_Lib/.venv/Scripts/alm-conn.exe" schedule remove --project $P --state-dir $S

# 2. wipe generated artifacts
Remove-Item "$S\state.json","$S\sync-meta.json","$S\action_history.json","$S\manual_sync.log","$S\state.json.sync.lock","$S\*.tmp" -ErrorAction SilentlyContinue
Remove-Item "$S\snapshots","$S\history","$S\reports","$S\scheduler" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item "C:\Users\foueslati\Usine_Agentique_Testing\Talan_Factory\_bmad-input" -Recurse -Force -ErrorAction SilentlyContinue

# 3. rebuild
& "Talan_Library/Connection_Sources_Lib/.venv/Scripts/alm-conn.exe" state-init --project $P --state-dir $S
& "Talan_Library/Connection_Sources_Lib/.venv/Scripts/alm-conn.exe" sync --project $P --state-dir $S

Pause it (task stays registered, stops firing — reversible with start):

$P="C:\Users\foueslati\Usine_Agentique_Testing\Talan_Factory\Talan_usine_config"
$S="C:\Users\foueslati\Usine_Agentique_Testing\Talan_Factory\_bmad_state"
& "Talan_Library/Connection_Sources_Lib/.venv/Scripts/alm-conn.exe" schedule stop --project $P --state-dir $S

Remove it (unregisters the Windows task entirely — this is the one to run before a clean rebuild):
